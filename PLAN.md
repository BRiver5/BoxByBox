# Box by Box — План реализации

> «Pack without the panic.»
> Переезд по коробкам: нумерованные коробки по комнатам, накапливаемый темп
> упаковки, оптимальный план «какую комнату в какой день», шанс успеть и набор
> «первая ночь» — какие коробки вскрыть первыми.

## 0. Архитектура и разрешения
Полностью локальное, `expo-sqlite`. `expo-notifications` удалён. `VIBRATE` —
вибрация (выключается). INTERNET и всё чувствительное — в `blockedPermissions`.

## 1. Дизайн
`#B81D14` — красный упаковочный скотч; фон `#F1F0EC`; крафт `#C79A62` (бирки
коробок), бирюза `#1F7A6E` (успеваем / первая ночь), янтарь `#B07614` (риск).
Архетип — **Tab Dashboard**: нижний таб-бар Home / Boxes / Plan / Stats,
на Home — мозаика 2-колоночных плиток.

## 2. Модель данных
| Таблица | Поля |
|---|---|
| rooms | id, name, kind, est_boxes, window_days (сколько дней до переезда комнатой ещё пользуешься) |
| boxes | id, num, room_id, label, weight, fragile, tags (json: вещи первой ночи), status open/sealed/unpacked, minutes, sealed_day, unpacked_day, created_day |
| model | pace (json) |
| settings | moveDay, weekdayMin, weekendMin, nightMin, wanted, extra:<date>, haptics, model_version |

## 3. Движок (`src/lib`)
- `pace.ts` — накапливаемая лог-нормальная модель «минут на коробку» по виду
  комнаты с забыванием, сжатие вид → общий → 30 мин.
- `packplan.ts` — план упаковки: окна комнат вложены (суффиксы шкалы до
  переезда), поэтому раскладка по возрастанию окна с ранними днями внутри
  окна оптимальна по опозданию и «неудобству» (паковать комнату, которой ещё
  пользуешься), сверено перебором; остаток — в самые поздние дни до окна;
  шанс успеть — нормальное приближение суммы по темпу; варианты исправления,
  проверенные пересчётом (час в день, помощник в выходной, длинный вечер).
- `firstnight.ts` — первая ночь: максимальное взвешенное покрытие нужных вещей
  за лимит времени — точный перебор с отсечением, сверен полным перебором.

## 4. Экраны (6)
Табы `index`, `boxes`, `plan` (Packing / First night / What if), `stats`;
`box/[id]` — деталь коробки; `settings`.
