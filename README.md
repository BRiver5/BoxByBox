# Box by Box

Pack without the panic. A local-only moving planner: number every box as you
start it, seal it with how long it took, and the app learns your real pace,
plans which room to pack on which day (keeping the rooms you still use for
last), tells you your chance of being ready, and picks the boxes to open first
on the first night.

## Run

```
npm install
npx expo start
```

`npm run verify` — typecheck, unit tests, project rules, offline export.
